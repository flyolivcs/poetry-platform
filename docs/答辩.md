# 中华古诗词学习平台 — 答辩材料

## 一、项目概述

### 1.1 项目名称
中华古诗词学习平台

### 1.2 项目简介
本项目是一个基于Web技术的中文古诗词学习与鉴赏平台，收录了1000首经典唐诗和1000首经典宋词（共2000首真实历史诗词），按10个题材类别分类展示，提供浏览、检索、收藏、点赞、视频管理等交互功能。

### 1.3 项目目标
- 传承中华优秀传统文化，以数字化形式呈现古典诗词
- 提供便捷的诗词学习工具，支持分类浏览和检索
- 实现完整的用户系统，支持个性化收藏和管理

## 二、技术亮点

### 2.1 真实数据保障
- 所有2000首诗词均来源于开源的chinese-poetry数据库
- 通过GitHub API获取真实历史诗词数据，非生成或虚构
- 涵盖李白、杜甫、白居易、苏轼、辛弃疾、李清照等著名诗人词人的作品

### 2.2 零依赖架构
- 后端使用Node.js内置http模块，无需安装任何npm包
- 前端使用原生HTML/CSS/JavaScript，无需框架依赖
- 部署简单，仅需Node.js运行环境

### 2.3 智能分类算法
- 基于关键词匹配的10类分类体系
- 结合标题和正文内容进行多维度匹配
- 分类体系参考中国古典文学研究的传统分类方法

### 2.4 完整功能体系
- 用户注册/登录/登出（Token认证）
- 诗词分类浏览 + 分页 + 搜索 + 筛选
- 收藏/取消收藏 + 点赞
- 个人视频收藏管理（增删查）
- 诗词详情展示 + 赏析信息

### 2.5 精美UI设计
- 采用中国传统配色方案（棕色、金色、墨色）
- 响应式布局，适配桌面和移动端
- 古风界面设计，营造文化氛围

## 四、功能演示流程

### 4.1 首页浏览
1. 打开平台首页，查看Hero区域和平台统计数据
2. 浏览10个类别卡片，每张卡片配有代表性图片和诗词数量
3. 查看"名篇推荐"区域的精选诗词

### 4.2 分类浏览
1. 点击任一类别卡片，进入该类别的诗词列表页
2. 使用筛选栏：按类别、类型（诗/词）、关键词进行筛选
3. 使用分页功能浏览更多诗词

### 4.3 诗词详情
1. 点击诗词卡片的"查看详情"按钮
2. 查看诗词全文、作者信息、分类标签
3. 查看诗词赏析和原文分段展示

### 4.4 用户注册与登录
1. 点击导航栏"注册"按钮，填写用户名和密码
2. 注册成功后自动登录，导航栏显示用户名
3. 退出后可使用"登录"功能重新登录

### 4.5 收藏与点赞
1. 登录后，在诗词卡片或详情页点击"收藏"
2. 点击"点赞"为诗词点赞
3. 导航栏点击"我的收藏"查看已收藏的诗词

### 4.6 视频管理
1. 登录后，导航栏点击"我的视频"
2. 在添加视频表单中填写视频标题和URL
3. 添加成功后可在列表中查看和播放视频
4. 可删除已添加的视频

## 七、常见问题及回答

### Q1: 诗词数据是否真实？
**A**: 是的，所有2000首诗词均来源于GitHub上开源的chinese-poetry数据库，该数据库收录了全唐诗、全宋词等真实历史诗词作品。我们通过GitHub API下载了原始数据文件，确保了诗词内容的真实性和权威性。

### Q2: 为什么选择Node.js而不是Python/Flask？
**A**: 主要基于环境兼容性考虑。开发环境中Python的pip包管理器存在网络超时问题，无法安装Flask。而Node.js v22环境完全可用，且使用内置http模块无需安装任何依赖，部署更简单。

### Q3: 分类算法是如何工作的？
**A**: 采用基于关键词匹配的分类算法。系统为每个类别定义了一组特征关键词（如"山水田园"类包含"山、水、田、园"等），通过统计诗词标题和正文中各类别关键词的出现次数，选择匹配分数最高的类别。若所有类别匹配分数为0，则随机分配。

### Q4: 用户密码如何存储？
**A**: 用户密码使用SHA-256哈希算法加密后存储，不保存明文。每次登录时，对输入密码进行同样的哈希计算，与存储的哈希值比较验证。

### Q5: 如何保证诗词数量达到要求？
**A**: 我们下载了4003首唐诗和4000首宋词的原始数据，按作者知名度排序后选取前1000首诗和前1000首词。知名度排序基于一个预定义的著名诗人列表（如李白、杜甫、苏轼等），排名越靠前的诗人其作品优先级越高。

### Q6: 视频收藏功能如何实现？
**A**: 用户登录后可在"我的视频"页面添加视频收藏。添加时需提供视频标题和URL（支持mp4直链）。系统将视频信息存储在db.json中，用户可查看、播放和删除已收藏的视频。

### Q7: 系统如何处理分页？
**A**: 后端API支持page和pageSize参数，返回对应页的数据以及总页数。前端实现完整的分页组件，包括首页、上一页、页码跳转、下一页、末页，并显示当前页码和总页数。

### Q8: 数据为什么是繁体字？
**A**: chinese-poetry数据库中的原始数据使用繁体字，这是为了保留古籍原貌。繁体字也是真实历史诗词的原始形式，具有一定的学术价值。未来可考虑增加繁简转换功能。
