# 中华古诗词学习平台 — 项目论文

## 摘要

本项目设计并实现了一个基于Web的中文古诗词学习平台，旨在利用现代互联网技术传承和弘扬中华优秀传统文化。平台收录了1000首经典唐诗和1000首经典宋词，共计2000首真实历史诗词作品，按照山水田园、边塞军旅、咏史怀古等10个题材类别进行分类展示。系统采用Node.js作为后端服务器，原生HTML/CSS/JavaScript作为前端，实现了用户注册登录、诗词浏览检索、分类筛选、分页展示、收藏点赞、个人视频收藏管理等核心功能。所有诗词数据均来源于开源的中华诗词数据库（chinese-poetry），保证了内容的真实性和权威性。

**关键词**：古诗词；Web应用；Node.js；分类检索；用户交互；传统文化数字化

---

## 1. 引言

### 1.1 研究背景

中国古典诗词是中华文化的瑰宝，承载着数千年的历史积淀和审美追求。从《诗经》《楚辞》到唐诗宋词，古典诗词以其精炼的语言、深远的意境和丰富的情感，成为世界文学史上的独特存在。然而，在数字化时代，如何利用现代技术手段让更多人便捷地接触、学习和欣赏古诗词，成为一个重要的文化传承课题。

### 1.2 研究意义

构建古诗词学习平台具有以下意义：
- **文化传承**：以数字化形式保存和传播古典诗词，让传统文化在新时代焕发生机
- **教育辅助**：为诗词学习者提供便捷的检索、分类和收藏工具
- **技术实践**：综合运用前后端技术，实现完整的Web应用开发流程
- **数据分析**：通过对诗词的分类标注，为诗词研究提供数据基础

### 1.3 项目目标

本项目旨在开发一个功能完整、交互友好的古诗词学习平台，具体目标包括：
1. 收录至少1000首经典名诗和1000首经典名词，且诗词必须真实存在
2. 将诗词按10个题材类别进行分类展示
3. 支持多页面浏览和分页功能
4. 实现用户注册、登录、登出功能
5. 支持诗词收藏和点赞功能
6. 支持个人收藏视频管理功能
7. 每个类别配备相关图片展示

## 2. 需求分析

### 2.1 功能需求

#### 2.1.1 诗词数据管理
- 系统需收录至少2000首真实古诗词（1000首诗+1000首词）
- 诗词数据包含标题、作者、朝代、类型（诗/词）、词牌名、正文内容等字段
- 所有诗词须分配至10个题材类别中

#### 2.1.2 分类展示
- 主界面展示10个主要类别，每个类别配有代表性图片
- 类别包括：山水田园、边塞军旅、咏史怀古、离别送行、爱情闺怨、节令风俗、咏物言志、叙事抒怀、禅理悟道、题画写意
- 点击类别可进入对应诗词列表页面

#### 2.1.3 浏览与检索
- 支持按类别、类型（诗/词）、关键词进行筛选
- 支持分页浏览，每页显示20首诗词
- 支持诗词详情查看，展示完整内容和赏析信息

#### 2.1.4 用户系统
- 支持用户注册（用户名+密码）
- 支持用户登录/登出
- 登录状态通过Token机制维持

#### 2.1.5 交互功能
- 支持对诗词进行点赞
- 支持收藏/取消收藏诗词
- 支持查看个人收藏列表
- 支持添加、查看、删除个人收藏视频

### 2.2 非功能需求
- **真实性**：所有诗词必须为真实存在的历史作品
- **可用性**：界面友好，操作直观，响应迅速
- **兼容性**：支持主流浏览器和移动端访问
- **安全性**：用户密码加密存储，Token身份验证

### 2.3 用户角色分析
- **未登录用户**：可浏览首页、分类、诗词列表和详情，不可收藏和点赞
- **已登录用户**：在未登录用户基础上，可收藏诗词、点赞、管理个人视频

## 3. 系统设计

### 3.1 系统架构

系统采用前后端分离的B/S架构：

```
┌─────────────────────────────────────────┐
│              前端（浏览器）               │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ │
│  │  首页面  │ │ 列表页面 │ │ 详情页面 │ │
│  └──────────┘ └──────────┘ └──────────┘ │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ │
│  │ 登录注册 │ │ 收藏页面 │ │ 视频页面 │ │
│  └──────────┘ └──────────┘ └──────────┘ │
└──────────────────┬──────────────────────┘
                   │ HTTP/JSON
┌──────────────────┴──────────────────────┐
│           后端（Node.js Server）          │
│  ┌──────────────────────────────────┐   │
│  │         API 路由层               │   │
│  │  /api/categories  /api/poems     │   │
│  │  /api/login  /api/favorite       │   │
│  │  /api/videos  /api/like ...      │   │
│  └──────────────────────────────────┘   │
│  ┌────────────┐  ┌─────────────────┐   │
│  │  数据层    │  │   静态文件服务   │   │
│  │ all_poems  │  │  HTML/CSS/JS    │   │
│  │ db.json    │  │                 │   │
│  └────────────┘  └─────────────────┘   │
└─────────────────────────────────────────┘
```

### 3.2 技术选型

| 层次 | 技术 | 说明 |
|------|------|------|
| 前端 | HTML5 + CSS3 + JavaScript(ES6) | 原生实现，无需框架依赖 |
| 后端 | Node.js v22 + http模块 | 使用内置模块，零依赖 |
| 数据存储 | JSON文件 | 轻量级存储，适合本项目规模 |
| 数据来源 | chinese-poetry开源数据库 | GitHub上权威的古诗词数据集 |
| 认证方式 | Token-based认证 | SHA-256加密 + 随机Token |

### 3.5 页面设计

系统共设计7个主要页面：
1. **首页（index.html）**：展示Hero区域、平台统计、10个类别卡片、名篇推荐
2. **诗词列表页（category.html）**：支持筛选、搜索、分页的诗词列表
3. **诗词详情页（detail.html）**：展示诗词全文、赏析、点赞收藏按钮
4. **登录页（login.html）**：用户登录表单
5. **注册页（register.html）**：用户注册表单
6. **收藏页（favorites.html）**：展示用户收藏的诗词列表
7. **视频页（videos.html）**：管理用户收藏的视频

### 3.6 分类算法设计

系统采用基于关键词匹配的分类算法，将诗词分配到10个类别中：

1. 提取诗词标题和正文的文本内容
2. 对每个类别，统计其关键词在文本中的出现次数
3. 选择匹配分数最高的类别作为诗词的分类
4. 若所有类别匹配分数为0，则随机分配

各类别的关键词设计参考了中国古典文学研究的传统分类方法，如"山水田园"类包含"山、水、田、园、林、溪"等字，"边塞军旅"类包含"塞、军、战、征、戍"等字。

## 4. 技术实现

### 4.1 数据获取与处理

数据来源于GitHub上的开源项目chinese-poetry，该项目收录了全唐诗、全宋词等大量古诗词数据。由于网络环境限制，本项目通过GitHub API（api.github.com）获取数据：

1. **获取文件树**：通过`/repos/chinese-poetry/chinese-poetry/git/trees/master`接口获取仓库文件列表
2. **下载诗词文件**：通过`/repos/.../contents/<path>`接口下载JSON文件（base64编码）
3. **数据处理**：对下载的4003首唐诗和4000首宋词进行去重、按作者知名度排序、选取前1000首
4. **分类标注**：使用关键词匹配算法将每首诗词分配到10个类别之一
5. **保存数据**：生成`all_poems.json`（2000首诗词）和`categories.json`（10个类别）

### 4.2 后端实现

后端使用Node.js内置的`http`模块创建服务器，无需安装任何第三方依赖：

- **静态文件服务**：直接读取并返回HTML/CSS/JS文件
- **API路由**：通过URL路径匹配实现RESTful API
- **数据持久化**：使用JSON文件（db.json）存储用户、收藏、点赞等数据
- **身份认证**：使用SHA-256加密密码，随机生成Token维持会话
- **端口检测**：启动时自动检测空闲端口，避免端口冲突

### 4.3 前端实现

前端采用原生HTML/CSS/JavaScript实现，无需任何框架：

- **CSS设计**：采用中国传统配色方案（棕色#8B4513、金色#C9A96E、墨色#2C1810），营造古风氛围
- **响应式布局**：使用CSS Grid和Flexbox实现自适应布局
- **交互逻辑**：通过fetch API调用后端接口，动态渲染页面内容
- **状态管理**：使用localStorage存储用户Token，维持登录状态
- **分页组件**：实现首页、上一页、页码、下一页、末页的完整分页功能

### 4.4 安全措施

- 用户密码使用SHA-256哈希加密存储，不保存明文
- 每次登录生成随机Token（32字节十六进制），用于后续请求认证
- API接口对需要登录的操作进行身份验证，未登录返回401状态码
- 前端对用户输入进行基本验证（用户名长度、密码长度等）

## 6. 总结与展望

### 6.1 项目总结

本项目成功实现了一个功能完整的中文古诗词学习平台，主要成果包括：

1. **数据真实可靠**：收录2000首真实历史诗词作品，数据来源于权威的开源数据库
2. **功能全面**：实现了分类浏览、分页展示、搜索筛选、用户认证、收藏点赞、视频管理等核心功能
3. **技术合理**：采用零依赖的Node.js后端和原生前端，部署简单，运行高效
4. **界面美观**：采用中国传统配色方案，营造浓厚的文化氛围
5. **分类科学**：基于关键词匹配的10类分类体系，覆盖中国古典诗词的主要题材

### 6.2 不足与展望

当前系统仍存在一些可改进之处：

1. **繁简转换**：当前数据为繁体字，可增加繁简转换功能
2. **诗词注解**：可增加诗词的注释、翻译和赏析内容
3. **朗诵音频**：可集成诗词朗诵音频，增强学习体验
4. **推荐算法**：可基于用户收藏历史实现个性化推荐
5. **社交功能**：可增加用户评论、分享等社交互动功能
6. **数据扩展**：可扩充至更多朝代的诗词作品（如元曲、明清诗词等）

### 6.3 结语

本项目通过现代Web技术实现了古诗词的数字化学习和传播，验证了利用互联网技术弘扬传统文化的可行性。系统不仅为诗词爱好者提供了便捷的学习工具，也为传统文化的数字化传承探索了一条可行路径。
